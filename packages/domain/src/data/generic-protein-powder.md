# Generic protein powder label profile

Profile version: `2026-08-19`

The household owner supplied these label values for the protein powders used in
the recipe library. MacroMap treats the flavour variants as nutritionally
equivalent and converts one scoop to 30 g.

| Per 100 g          |    Value |
| ------------------ | -------: |
| Energy             | 371 kcal |
| Protein            |     74 g |
| Carbohydrate       |    6.8 g |
| of which sugars    |    4.1 g |
| Fat                |    4.5 g |
| of which saturates |    1.8 g |
| Fibre              |    2.5 g |
| Salt               |   0.51 g |

MacroMap calculates only energy, protein, carbohydrate, and fat. The other
label values are retained here as source documentation but remain outside the
MVP nutrition scope.
